# 麦麦遛娃点餐师（MaiMai-Kids-Order）

> 两大一小家庭场景的麦当劳 WorkBuddy Skill，一句话算出带娃最省家庭餐。

## 痛点

家长周末带娃吃麦当劳常遇三难：
- 开心乐园餐玩具不知道有没有
- 甜饮想换牛奶/苹果片不会操作
- 成人餐+儿童餐+满减券组合算不过来

## 功能

- 识别两大一小家庭上下文
- 真实调用麦当劳 MCP 拉门店/菜单/券/活动
- 固定输出三套方案：全家稳 / 孩子开心 / 家长友好
- 乐园餐甜饮→牛奶/苹果片自动提示
- 下单双确认（preview + 字面"确认下单"）

## 对话示例

> 👤 用户：周末中午，带孩子，两大一小，预算70，别太甜，要有玩具/开心乐园餐。

> 🤖 麦麦遛娃点餐师：已识别开心乐园餐档期🎈（当前小汽车玩具款）

| 方案 | 内容 | 原价 | 家庭实付 | 备注 |
|---|---|---:|---:|---|
| 👨👩👦全家稳 | 2成人板烧套餐+1乐园餐(去甜饮换牛奶) | 76 | 61 | 满60减8命中 |
| 🍟孩子开心 | 1双层+1麦辣+1乐园餐 | 72 | 64 | 有玩具，甜饮保留 |
| 🥗家长友好 | 2板烧单点+玉米+乐园餐 | 68 | 58 | 整体更低卡 |

提示：乐园餐默认配苹果片可换，已勾换牛奶，下单前可改。选好说一声我锁门店。
